# CodeAlpha_Age-Calculator
An Age Calculator web application developed using HTML, CSS, and JavaScript as part of my CodeAlpha Internship.
This project calculates a user’s exact age in years, months, and days based on the entered date of birth.
It features a simple, user-friendly interface, input validation, and real-time results, helping strengthen my understanding of JavaScript date handling, DOM manipulation, and responsive design.

Technologies Used:
HTML | CSS | JavaScript
